# Autonomous Vehicle Path Planner & Trajectory Control 🚗🧭

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)
[![Domain](https://img.shields.io/badge/Domain-Autonomous%20Vehicles%20%26%20Robotics-orange.svg)](#)
[![Tech](https://img.shields.io/badge/Tech-RRT*%20%7C%20Hybrid%20A*%20%7C%20Obstacle%20Avoidance-brightgreen.svg)](#)

A motion planning platform for autonomous mobile robots (AMRs) and self-driving vehicles implementing **$RRT^*$ (Rapidly-exploring Random Trees)**, **Hybrid $A^*$**, and collision-free kinematic trajectory synthesis.

---

## 🌟 Key Features
- 🧭 **Optimal Path Planning:** Rapidly discovers asymptotic shortest paths around complex multi-body obstacles.
- 🚗 **Kinematic Feasibility:** Enforces vehicle non-holonomic turning radius limits.

---

## 🚀 Quick Start
```bash
git clone https://github.com/rushikeshgarad2024-dev/autonomous-vehicle-path-planner.git
cd autonomous-vehicle-path-planner
npx serve .
# Or run Python planner:
python rrt_planner.py
```
